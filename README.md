<h2 align="center">FLOWBITE CRUD</h2>

###

<p align="left">A web-based student data CRUD project using tailwind and flowbite that I created with the aim of understanding how the system can work and facilitate several activities so that it is widely used by the community in several aspects of activities, especially in managing or processing data.</p>

###

<h3 align="left">Features Developed :</h3>

###

<p align="left">➕ Enter Student Data<br>📝 Edit Student Data<br>👁️ View Student Data<br>🔍 Search Student Data<br>🗑️ Delete Student Data</p>
